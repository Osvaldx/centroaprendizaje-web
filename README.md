# 🌐 Centro Aprendizaje - Landing Page

Landing page institucional desarrollada para el instituto de **Centro de Aprendizaje**, un espacio educativo con sede en Argentina.  
El sitio fue diseñado y desarrollado como proyecto freelance.

---

---
## 🚀 Tecnologías Utilizadas

- **Framework:** Angular 20
- **Lenguajes:** HTML5, TypeScript, TailwindCSS
- **Diseño:** UI amigable y responsive
- **Hosting:** [Hostinger](https://www.hostinger.com/)  
- **Dominio:** [centroaprendizaje.com.ar](https://centroaprendizaje.com.ar)
